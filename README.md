## 🚀 Tecnologias Utilizadas

- **HTML5**: Estruturação semântica, acessibilidade e metadados SEO/Open Graph.

## ⚡ Como Publicar na Vercel

Por ser um projeto puramente estático (Vanilla HTML/CSS/JS), a publicação na [Vercel](https://vercel.com) é instantânea:

1. Acesse o seu painel na **Vercel** (`https://vercel.com`).
2. Clique em **"Add New..."** > **"Project"**.
3. Conecte sua conta do GitHub e selecione o repositório `portfolio-giulia-ribeiro`.
4. Mantenha as configurações padrão (Framework Preset: **Other** / Root Directory: `./`).
5. Clique em **"Deploy"**.
6. Pronto! O site estará no ar em poucos segundos com HTTPS automático.
